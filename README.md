# 图片尺寸工具

一个纯前端的本地图片尺寸转换工具。打开 `index.html` 后选择图片，设置目标宽高、适配方式、导出格式、质量和切图规则，即可下载指定分辨率的图片。

## 使用方式

直接用浏览器打开：

```bash
open index.html
```

支持：

- 自定义任意目标宽高
- 常用尺寸预设，例如 640x640、1080x1080、16:9、9:16、3:4、4:3
- 完整显示、铺满裁剪、拉伸变形
- 铺满裁剪时选择裁剪位置
- PNG、JPEG、WebP 导出
- JPEG/WebP 质量设置
- 文件大小上限，例如 640x640 且小于 500KB
- 实时预估导出大小
- 按 m x n 切图，例如 3 x 3 自动输出 9 张图片
- 输出预览显示切图线
- 多图上传和批量导出 ZIP
- 锁定原图比例
- 拖放上传

注意：

- 极大的目标分辨率会受到浏览器 Canvas 内存和尺寸限制。
- 设置文件大小上限时，JPEG/WebP 会自动尝试降低质量。PNG 不能可靠通过质量参数控制体积，因此会自动改用 JPEG 导出。
- 切图数量大于 1 时会下载一个 ZIP，里面包含所有切好的图片。
- 多图上传时会按当前设置批量处理，最终下载一个 ZIP。
